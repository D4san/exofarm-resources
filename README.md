# ExoFarm — Research Resources

Companion website for the scientific poster **Atmospheric Technosignatures in ExoFarm Scenarios around M-Dwarf Stars**.

Authors: David Santiago Duque Castaño, Jorge I. Zuluaga, Lauren Flor-Torres.

The page presents a public overview of the research, photochemical methodology, selected synthetic-observation results, poster materials, a curated reference list, and manuscript status. It does **not** publish the unpublished manuscript.

## Deploy

1. Upload the files in the website ZIP **at the root of this repository**, including `assets/` and `downloads/`.
2. In GitHub Settings → Pages → Build and deployment select **Deploy from a branch**, **main**, **/(root)**.
3. Visit https://d4san.github.io/exofarm-resources/ after Pages reports a successful deployment.

The QR printed on the poster targets this URL. Keep the repository name unchanged.

## Sources

Site text is based on the supplied final poster, extended poster, and the main LaTeX document strictly **before** the `{HASTA AQUÍ VAMOS}` marker. The manuscript is not publicly distributed here.

- `D4san/exofarm`: scientific code and analysis.
